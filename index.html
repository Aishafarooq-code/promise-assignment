Question: 1

Bank Account Withdrawal
Create a Promise for withdrawing money.
Conditions:
- Account balance = Rs. 10,000
- Withdrawal amount = Rs. 7,000
- If balance is sufficient, resolve the Promise.
- Otherwise, reject the Promise.
Use .then() and .catch() to display the result.

Question: 2

Online Exam Result
Create a Promise that checks student results.
- Marks 50 or above: Pass.
- Marks below 50: Fail.
- Marks greater than 100 or less than 0: Invalid marks.
Handle the result using .then() and .catch().

Question: 3

Product Delivery System
Create a Promise for an online shopping delivery.
Use setTimeout() to simulate a 3-second delivery process.
- After 3 seconds, resolve with "Product Delivered Successfully".
- If delivery is unsuccessful, reject with "Delivery Failed".
Display the result using .then() and .catch().
